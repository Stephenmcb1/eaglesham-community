# Map data

GeoJSON files used by the maps live in `public/data/`. Everything in `public/` is published as-is, so **nothing private or sensitive goes in that folder**.

## Where it comes from

All files are generated by `scripts/fetch_ldp3_data.py` from East Renfrewshire Council's public ArcGIS map service for the Proposed LDP3 (the service behind the council's "LDP3 Proposals Maps for Consultation" web map). The council's data is in British National Grid. The script converts it to WGS84 using the OSTN15 grid, which is accurate to about 1 metre, so the boundaries are the council's own lines, not traced copies.

To refresh after the council updates its maps:

```bash
pip install pyproj shapely numpy
python scripts/fetch_ldp3_data.py
```

Last fetched: 2 November 2026.

## Properties

`eaglesham-sites.geojson`:

```json
{ "id": "waulkers-loan", "name": "Waulkers Loan", "ldpRef": "Strat 1.8", "areaHa": 9.2, "indicative": false, "source": "…" }
```

`id` matches `mapFeatureId` in the site's file in `src/content/sites/`. `areaHa` is measured from the council's geometry. The council's own data spells the site "Waukers Loan", and we use the usual spelling.

All other files have `ldpRef`, `name` and `desc` (the council's policy reference, site name and description). Proposals also have `schedule`.

## Useful facts from this data (checked 2 November 2026)

- Site areas: Eaglesham North 59.0 ha, Holehouse Road 5.07 ha, Waulkers Loan 9.2 ha
- In the adopted LDP2 (March 2022), all three sites are entirely green belt. Checked against the council's LDP2 map service, layer "D3 Green Belt".
- In the proposed LDP3, about 31.5 ha of Eaglesham North stays green belt (the green network). The rest of the three sites would be released.
- Holehouse Road and Waulkers Loan both touch the Eaglesham Conservation Area boundary.

Check these against the plan's written statement before quoting them on the site.

## Never put in `public/data/`

- Badger setts, bat roosts or any other sensitive wildlife locations
- Anything with people's names, addresses or contact details
