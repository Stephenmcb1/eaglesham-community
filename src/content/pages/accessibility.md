We want everyone in Eaglesham and Waterfoot to be able to use this site. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

## You should be able to

- zoom in up to 400% without text spilling off the screen
- use the whole site with a keyboard only
- use the site with a screen reader
- read every map's information as text as well
